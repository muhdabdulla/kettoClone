# KEAM Portal Project Report (Overleaf LaTeX Source)

This folder contains the complete, professionally formatted academic project report for the **KEAM Portal: Full-Stack Entrance Examination and Admission Management System** (Course Code: `24CSJ303: ADVANCED PROGRAMMING - PROJECT REPORT`) at **TKM College of Engineering (Govt. Aided and Autonomous), Kollam**.

## Directory Structure
- `main.tex`: Master LaTeX document incorporating the exact TKM template (Title Page, Certificate, Declaration, Acknowledgement, Abstract, Table of Contents, 10 Chapters, Code Snippets, and References).
- `images/`: High-resolution figures and logos:
  - `tkm_logo.png`: Official TKM College of Engineering seal (extracted from previous year template).
  - `cee_logo.png`: Commissioner for Entrance Examinations (CEE Kerala) emblem.
  - `landing_page.png`: Landing page with government band and scrolling ticker.
  - `landing_page_cards.png`: Course stream tabs and portal action cards.
  - `login_page.png`: Authentication screen with CAPTCHA verification.
  - `register_page.png`: Candidate registration interface.
  - `password_meter.png`: Real-time 4-tier password strength visualizer.
  - `application_form.png`: 6-step multi-step application form wizard.
  - `status_page.png`: Public application milestone status tracker.
  - `admin_portal.png`: Administrator applications scrutiny console.
  - `admin_announcements.png`: Live announcement and ticker manager.

## How to Compile in Overleaf
1. Log into your Overleaf account (https://www.overleaf.com).
2. Click **New Project** -> **Upload Project**.
3. Select and upload the pre-packaged zip archive:
   `keam_project_report.zip`
4. Overleaf will automatically unpack `main.tex` and the `images/` directory.
5. Set compiler to **pdfLaTeX** (default) and click **Recompile**.
